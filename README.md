# fuxion.site — Catálogo Oficial y Portal Transaccional FuXion Perú (PEN / S/)

Sitio web de alto rendimiento SEO desarrollado con **Next.js 16 + React 19 + TypeScript + Tailwind CSS v4**, diseñado para el mercado de **Perú** en moneda **Soles (`S/`)** y conectado directamente a la tienda oficial **`https://shop.site.fuxion.com/`**.

## Características Principales
- **Identidad Visual Oficial (`fuxion-theme`):** Paleta de colores exacta (`#0093DD`, `#007CBC`, `#8CC63F`, `#12232E`, `#EDF7FD`, `#EFFBC4`), tipografías `Outfit` e `Inter`, logotipos y sellos oficiales.
- **Catálogo Completo (72 SKUs en 60 páginas de producto):** Cada producto cuenta con selector de presentación, precios en Soles, cálculo por stick, ingredientes activos, preparación, tabla nutricional y enlaces transaccionales directos a `https://shop.site.fuxion.com/{landing}/` o `https://shop.site.fuxion.com/producto/{sku}/`.
- **Hub de Contenidos SEO (+105 Artículos):** Artículos especializados orientados a Perú con `<TransactionalProductCard />` integrada dentro del cuerpo del artículo.
- **Páginas Legales (Lima, Perú):** Titularidad a nombre de **CARLOS EDEN LINGAN BORJA**, domiciliado en **Lima, Perú**.
